1. PROJECT OVERVIEW
--------------------------------------------------------------------------------

Project Name   : PathPilot — AI Career Assistant
Application ID : AI Career Assistant (configurable via .env)
Version        : 1.0.0
Description    : A full-stack, AI-powered career guidance and skill-gap
                 analysis platform designed to help students and early-career
                 professionals plan their careers, improve their resumes,
                 prepare for interviews, and build structured learning roadmaps.

The platform uses Google Gemini AI to generate personalized, actionable
career advice based on a user profile. All reports are stored in a
cloud-hosted PostgreSQL database (Supabase) for later retrieval.


--------------------------------------------------------------------------------
2. PROJECT OBJECTIVES
--------------------------------------------------------------------------------

1. Generate personalized career recommendations from a structured user profile.
2. Identify skill gaps and create actionable 12-week learning milestones.
3. Provide role-specific resume feedback and interview practice material.
4. Persist user profiles and AI-generated reports in a relational database
   for later retrieval and review.
5. Expose a clean REST API that can be extended with authentication, course
   integrations, and analytics in future versions.

Data Flow:

  2. JavaScript sends JSON POST to FastAPI endpoint
  3. FastAPI builds an AI prompt from user data
  4. Gemini API returns a Markdown-formatted career report
  5. FastAPI saves the result to Supabase (career_reports table)
  6. JSON response is returned to the browser
  7. JavaScript renders the Markdown result in the UI

6. FEATURES / MODULES
--------------------------------------------------------------------------------

MODULE 1 — CAREER ASSESSMENT (01 / DISCOVER)
  Endpoint : POST /api/career-plan
  Form     : Full name, education, interests, skills, experience level,
             target role (optional), study hours per week
  Output   : Personalized career roadmap including:
               - 3 suitable career path recommendations
               - Skill gap analysis table
               - 12-week weekly learning plan
               - 3 portfolio project suggestions
               - Recommended learning resources
               - 30-day first action plan
               - Risks and next steps
  Database : Saves user profile to career_profiles;
             saves AI report to career_reports.

MODULE 2 — RESUME INTELLIGENCE (02 / IMPROVE)
  Endpoints: POST /api/resume-review   (text input)
             POST /api/resume-upload   (PDF upload, max 5 MB)
  Input    : Resume text or text-based PDF + optional target role
  Output   : Resume review report including:
               - Overall assessment
               - Strong points
               - Issues to fix (prioritized)
               - ATS/keyword alignment notes
               - 3 before-and-after bullet rewrites
               - Missing evidence to add
               - Suggested skills to learn
               - 5 tailoring actions
  Notes    : PDF text extracted via pypdf; scanned PDFs not supported.

MODULE 3 — INTERVIEW STUDIO (03 / PRACTISE)
  Endpoint : POST /api/interview-prep
  Input    : Target role, experience level, difficulty, question count (3-15)
  Output   : Interview preparation pack including:
               - Role-specific questions (default: 8)
               - What each question tests
               - Answer framework (STAR for behavioural questions)
               - Follow-up question for each
               - 1-day practice schedule
               - 5 questions the candidate can ask the interviewer

MODULE 4 — LEARNING ROADMAP (04 / GROW)
  Endpoint : POST /api/course-roadmap
  Input    : Career goal / context (free text) + optional target role
  Output   : Structured learning roadmap including:
               - Prerequisite check
               - Ordered topics
               - Hands-on practice tasks
               - 3 portfolio milestones
               - Recommended free learning resources
               - Weekly checkpoints

MODULE 5 — SAVED REPORTS
  Endpoint : GET /api/history?limit=N  (1-50, default 10)
  Output   : List of previously generated reports with ability to open
             full report text in a new browser tab.

MODULE 6 — SYSTEM HEALTH CHECK
  Endpoint : GET /api/health
  Output   : JSON showing AI configured, database configured, app name,
             and active Gemini model name.

8. DATABASE DESIGN
--------------------------------------------------------------------------------

TABLE: career_profiles
  Column            Type          Notes
  id                UUID (PK)     Auto-generated (gen_random_uuid)
  full_name         TEXT          User full name
  education         TEXT          Degree / qualification
  interests         TEXT          Free-text interests
  skills            TEXT          Free-text current skills
  experience_level  TEXT          Default: 'Student / Fresher'

  Column            Type          Notes
  id                UUID (PK)     Auto-generated (gen_random_uuid)
  profile_id        UUID (FK)     References career_profiles.id (nullable)
  report_type       TEXT          'career_plan', 'resume_review',
                                  'interview_prep', 'learning_roadmap'
  input_summary     JSONB         JSON snapshot of user inputs
  ai_result         TEXT          Full Markdown from Gemini AI
  model_name        TEXT          Gemini model used
  created_at        TIMESTAMPTZ   Auto-set to current timestamp

INDEXES:
  career_reports_created_at_idx   On created_at DESC (for history queries)
  career_reports_profile_id_idx   On profile_id (for joins)

14. SECURITY AND LIMITATIONS
--------------------------------------------------------------------------------

SECURITY
  * API keys (GEMINI_API_KEY, SUPABASE_KEY) are server-side only.
  * Keys are loaded from .env — never exposed in JavaScript.
  * .env is in .gitignore and must not be committed.
  * The Supabase service-role key bypasses RLS — demo only.

LIMITATIONS
  * No user authentication — all users share one data namespace.
  * No rate limiting — AI endpoint can be called freely.
  * No request logging beyond Supabase row timestamps.
  * Scanned (image-only) PDFs are not supported by pypdf.
  * AI suggestions are planning support, not job guarantees.
  * Gemini model names change; update GEMINI_MODEL in .env if needed.

FOR PRODUCTION
  * Add Supabase Auth + user_id columns + per-user RLS policies.
  * Add rate limiting (e.g., slowapi).
  * Add request logging and data retention controls.
  * Serve over HTTPS via a reverse proxy (nginx, Caddy).

16. AI PROMPT STRATEGY
--------------------------------------------------------------------------------

Career Plan    — Includes full user profile JSON; instructs Gemini to act
                 as "PathPilot" career coach; specifies 7 Markdown sections.

Resume Review  — Includes resume text and target role; requests 8 specific
                 Markdown sections including before/after bullet rewrites.

Interview Prep — Specifies role, level, difficulty, count; requests STAR
                 framework for behavioral questions + 1-day practice plan.

Learning Roadmap — Includes career goal text; requests prerequisite check,
                   ordered topics, milestones, and free resource links.

All prompts instruct the AI to:
  * Use clean Markdown formatting
  * Not fabricate information or credentials
  * Not guarantee employment outcomes

17. KEY DESIGN DECISIONS
--------------------------------------------------------------------------------

1. FastAPI chosen for automatic Swagger docs, async support, and Pydantic
   validation — suitable for academic demonstration.

2. Vanilla JS frontend (no React/Vue) to minimize dependencies and keep
   the project self-contained for academic submission.

3. Supabase used as PostgreSQL host to avoid local database installation,
   enabling easy demo without local DB setup.

4. Gemini model is configurable via .env so the demo adapts to quota/model
   availability without code changes.

5. PDF extraction done server-side (pypdf) to avoid sending raw binary to
   the AI API directly.

6. Lazy initialization of Supabase and Gemini clients — connections created
   only on first use, preventing startup errors if .env is incomplete.

7. Skills and interests stored as plain TEXT (not PostgreSQL text[] array)
   to avoid type conversion issues in the demo schema.

19. PROJECT SUMMARY / ABSTRACT
--------------------------------------------------------------------------------

PathPilot is an AI-powered career intelligence platform built as a final-year
project. It integrates Google Gemini AI with a FastAPI backend and a Supabase
PostgreSQL database to deliver four intelligent career services:

  (1) Personalized Career Planning — converts a student education, skills,
      and interests into a structured 12-week roadmap with career matches,
      portfolio project ideas, and learning resources.

  (2) Resume Intelligence — reviews resume text or PDFs against a target
      role, highlighting weaknesses, keyword gaps, and improved bullets.

  (3) Interview Studio — generates tailored interview questions with answer
      frameworks (STAR method) and a structured practice schedule.

  (4) Learning Roadmap — converts a free-text career goal into an ordered
      curriculum with weekly checkpoints and milestone projects.

All AI-generated reports are stored in a cloud database and can be revisited
through the Saved Reports view. The frontend is a responsive single-page
application with no external framework dependency. The backend exposes a
documented REST API via Swagger UI, making it extensible for authentication,
course data integration, and analytics in future iterations.
